# 🐾 בניית קו משלוחים לפי כתובות

כלי פשוט למשלוחני אוכל לחיות: מכניסים כתובות, ומקבלים את סדר הנסיעה הכי קצר.

## איך משתמשים
1. פותחים את `index.html` בדפדפן (גם בטלפון).
2. ממלאים **נקודת יציאה** (מחסן / חנות).
3. מדביקים **כתובות** – אחת בכל שורה. אפשר להוסיף הערה אחרי `|`, למשל:
   `רוטשילד 5, ראשון לציון | דנה - שק 15 ק"ג לכלב`
4. לוחצים **🚚 בנה קו**.

## מה מקבלים
- רשימה ממוספרת לפי סדר הנסיעה + מפה.
- כפתור **Waze** / **Google Maps** לכל עצירה.
- כפתור לפתיחת כל הקו ב-Google Maps.
- שליחת הקו לנהג בוואטסאפ.
- סימון "✔ נמסר" לכל משלוח.
- הכתובות נשמרות בדפדפן לפעם הבאה.

אין צורך בהתקנה או במפתח API (משתמש ב-OpenStreetMap ו-OSRM החינמיים).
