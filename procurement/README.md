# רכש וייבוא – Ashtal Europet

תיקיית עבודה לצוות סוכני ה-AI לרכש בינלאומי (מוצרים לבעלי חיים מסין).
שלב 1: ארכיטקטורה, הגדרת תפקידים, ספקים ראשונים וטיוטות מיילים. **לא נשלח שום דבר.**

## ארכיטקטורה (פשוטה וחסכונית)

- **מנהל הרכש = Claude Code עצמו** (השיחה הראשית). הוא מחלק עבודה, קורא ומעדכן את הקבצים, ומציג החלטות לאישור.
- **אין שרת, אין ממשק, אין מסד נתונים חיצוני.** כל המידע נשמר כקבצי CSV / Markdown בתיקייה הזו (git = היסטוריה מלאה).
- **סוכני משנה רק כשמשתלם:** מחקר רחב (הרבה אתרים במקביל) או ניתוח קבצי מחירון גדולים. פעולות קטנות – Claude Code עושה בעצמו.
- **לפני כל מחקר** – בודקים קודם ב-`data/suppliers.csv` אם המידע כבר קיים.

| תיקייה / קובץ | תפקיד |
|---|---|
| `data/suppliers.csv` | טבלת ספקים אחת לכל הצוות (מקור אמת) |
| `outbox/` | טיוטות מיילים יוצאים – סטטוס `ממתין לאישור` עד שתאשר |
| `inbox/` | סיכומי תשובות ספקים (מידע מחולץ, לא המיילים המלאים) |
| `analysis/` | השוואות מחירים, עלות נחיתה, הצעת הזמנה |
| `branding/` | בריף מיתוג, מפרט אריזות, dieline |
| `logistics/` | CBM, רשימות אריזה, צ'קליסט QC, תקינה |
| `ROLES.md` | הגדרת ששת התפקידים והכללים |
| `PROGRESS.md` | דוח התקדמות קצר |

## כלים קיימים בסביבה (נבדק 10.11.2026)

| כלי | מצב | שימוש |
|---|---|---|
| חיפוש ושליפת אתרים (WebSearch / web-fetch) | זמין | מחקר ספקים |
| סוכני משנה (Agent) | זמין | מחקר מקבילי כשצריך |
| **Gmail** (מחבר מורשה) | **מחובר** | קריאה, טיוטות, שליחה – שליחה רק באישורך |
| קריאת Excel / PDF / Word | זמין (skills) | ניתוח מחירונים וקטלוגים |
| Alibaba / Made-in-China API | אין | רק דרך האתרים הציבוריים |
| WhatsApp / WeChat | אין | ידני על ידך |

## כללי ברזל

1. אין שליחת מייל, תשלום, הזמנה, התחייבות או העברת מסמך רגיש בלי אישור מפורש.
2. אין להעביר סיסמאות / מפתחות API לספקים או לסוכני משנה.
3. כל נתון מסומן: **מאומת** (מקור + קישור) / **לא מאומת** / **הערכה**.
4. אין להמציא מחירים, שערים, עלויות שילוח או נתוני מוצר.
5. הסוכנים לא מחליפים עמיל מכס, בודק תקינה או חברת QC.
