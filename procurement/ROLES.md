# ששת התפקידים

הסוכנים מוגדרים כ-subagents של Claude Code בתיקייה `.claude/agents/`:

| תפקיד | קובץ | הרשאות |
|---|---|---|
| מנהל | Claude Code (השיחה הראשית) | הכול, שליחה רק באישורך |
| איתור מפעלים | `supplier-research.md` | חיפוש וקריאת אתרים בלבד |
| תקשורת | `supplier-communication.md` | קריאת Gmail בלבד + כתיבת טיוטות לקבצים. **אין לו הרשאת שליחה** |
| ניתוח מחירים | `price-analyst.md` | קבצים בלבד |
| מיתוג ואריזות | `private-label-packaging.md` | קבצים בלבד |
| שילוח ואיכות | `logistics-quality.md` | קבצים + חיפוש |

הסוכנים רצים על מודל חסכוני (sonnet). רק המנהל יכול לשלוח מייל, ורק אחרי אישור שלך.

כל התפקידים מבוצעים כברירת מחדל על ידי Claude Code בשיחה הראשית. סוכן משנה מופעל רק כשכתוב "סוכן משנה: כן".
כל תפקיד קורא וכותב רק לתיקיות שלו, ומעדכן את `data/suppliers.csv`.

## 1. Procurement Manager – מנהל (Claude Code עצמו)
- מחלק משימות, בודק שאין עבודה כפולה, מרכז המלצות.
- מציג לך רשימת "ממתין לאישור" בסוף כל שלב.
- מעדכן `PROGRESS.md`.
- סוכן משנה: לא.

## 2. Supplier Research – איתור מפעלים
- מקורות: אתרי היצרנים, Alibaba, Made-in-China, Global Sources, רשימות מציגים בתערוכות (Interzoo, Zoomark, Canton Fair).
- בודק: קטגוריות, OEM/ODM/Private Label, קטלוג רחב (לאיחוד משלוח), שנת הקמה, ניסיון ייצוא, תעודות (BSCI, ISO9001, SMETA וכו').
- מבדיל מפעל / חברת מסחר (סימנים: גודל מפעל, כתובת אזור תעשייה מול משרד, רישום כ-Manufacturer).
- מדרג 1–5 ומסמן כל נתון לא מאומת.
- פלט: שורות ב-`data/suppliers.csv`.
- סוכן משנה: כן, רק לסבב חיפוש רחב של 10+ ספקים.

## 3. Supplier Communication – תקשורת
- מכין מיילים באנגלית בשם Ashtal Europet ב-`outbox/`.
- מבקש: קטלוג, מחירון FOB, MOQ, זמני ייצור, מיתוג, תעודות, מידות קרטון.
- קורא תשובות ב-Gmail (קריאה בלבד), מחלץ נתונים ל-`inbox/`, מכין שאלות המשך ותזכורות (אחרי 5 ימי עבודה).
- **כל מייל יוצא – רק אחרי "מאשר" ממך.** טיוטת Gmail נוצרת רק באישורך.
- סוכן משנה: לא.

## 4. Price & Product Analyst – ניתוח מחירים
- קורא Excel/PDF מהמפעלים, משווה מוצרים דומים.
- מחשב FOB, אריזה, MOQ, עלות נחיתה (רק לפי נתונים מאומתים + הנחות מסומנות), רווח גולמי לפי מחירי המכירה שתספק.
- מכין הצעת הזמנה בתוך התקציב.
- פלט: `analysis/`.
- סוכן משנה: כן, רק כשיש הרבה קבצי מחירון במקביל.

## 5. Private Label & Packaging – מיתוג ואריזות
- בריף עיצובי אחיד, אפשרויות לוגו על מוצר ואריזה, בקשת dieline.
- מרכז ברקודים, מידות, צבעים, טקסט בעברית.
- אין אישור עיצוב סופי / התחייבות להדפסה בלי אישורך.
- פלט: `branding/`.

## 6. Logistics & Quality – שילוח ואיכות
- מידות קרטון, משקל, CBM, איחוד ממספר מפעלים, רשימות אריזה.
- בקשות הצעת מחיר משלחים (באישורך).
- צ'קליסט QC לפי קטגוריה, זיהוי מוצרים שדורשים בדיקת תקינה / סימון בישראל.
- הכנת חומר לעמיל מכס ולחברת בקרה – לא מחליף אותם.
- פלט: `logistics/`.
